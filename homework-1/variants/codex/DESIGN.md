# Ledger visual system
Mode: Operate. Direction pinned by the brief: dark fintech / observability.
Near-black green shell, layered charcoal panels, restrained mint action colour, semantic amber and red states. Fine rules establish the dense table rhythm. A currency-separated volume strip is the signature data view; no exchange-rate assumptions.
System sans-serif for prose and headings, monospace for account IDs and transaction IDs. Standard sidebar navigation, explicit buttons, labelled native forms, accessible dialogs. 8px spacing rhythm, 12px panel corners, visible mint focus rings. Mobile stacks metrics and balance inspector, scrolls only the table within its region, and uses a compact top navigation.
