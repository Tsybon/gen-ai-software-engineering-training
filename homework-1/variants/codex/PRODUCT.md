# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Delegated by the brief: Node.js built-in HTTP servers, plain JavaScript, HTML and CSS. No runtime package installation needed.
## Product Purpose
A working banking transaction API and responsive transaction operations dashboard for a course task.
## Users
Assumption: an operator creates transactions, investigates their status, and checks balances by currency.
## Capabilities and Constraints
In-memory transactions; positive amounts with up to two decimals; ISO currency validation; account, type and date filters; transaction details; account balances; summary, interest and CSV export. CORS allows all origins. API and UI run on separate configurable ports.
## Brand Commitments
Brief specifies dark fintech / observability style and usability at 390px. Ledger is an assumed interface label, not a commercial identity claim.
## Evidence on Hand
No supplied assets or existing data. Optional demo transactions must each be visibly labelled DEMO.
## Product Principles
Currency totals remain separate. Errors explain recovery. No fabricated live data or financial claims. Core flows work with keyboard input.
